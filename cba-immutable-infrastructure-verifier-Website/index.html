cba-immutable-infrastructure-verifier

The Mould Floor. A command line verifier that carries a system back to the shape declared for it: it validates that the system's configuration matches its declared immutable infrastructure definition, checking the files, services, and configurations the definition names.

The repository main.py
What is checkedThe presence and integrity of specific files, services, and configurations defined in the infrastructure as code
Checked againstThe declared immutable infrastructure definition, for example one defined in Terraform or Ansible
A passing runReports how many checks it performed
Dependenciesjsonschema and PyYAML

The README does not guess which file --definition points to, what values --type takes, or what --schema validates against, and neither does this site.

Stated limits

  • A definition with no files and no services entries is a configuration error and exits 2, because nothing was checked.
  • A passing run reports how many checks it performed.
  • --definition, --type, and --schema are each listed with no description provided; no descriptions, defaults, or accepted values are invented for them here.
